FUNDAMENTOS DA WEB

Página Estática:

Definição:

Uma página estática é uma página da web que o conteúdo permanece o mesmo para todos os usuários. Ela é criada, normalmente, utilizando HTML e CSS, e suas informações só são alteradas quando um desenvolvedor modifica o código da página.

Exemplo: Uma página institucional contendo informações sobre uma empresa, como endereço, telefone e horário de funcionamento.

Página Dinámica:

Definição:

Uma página dinâmica é uma página da web que o conteúdo pode ser alterado de acordo com a interação do usuário, os dados armazenados em um banco de dados ou outras informações processadas pelo servidor.

Exemplo: Uma loja virtual, na qual os produtos, os preços e as recomendações podem mudar de acordo com cada usuário.

Caminho básico entre navegador, servidor e resposta

Definição:

1 - O usuário digita o endereço da página no navegador.
2 - O navegador envia uma solicitação ao servidor.
3 - O servidor recebe a solicitação e processa as informações.
4 - Em uma página dinâmica, o servidor pode consultar um banco de dados.
5 - O servidor gera uma resposta e envia os dados ao navegador.
6 - O navegador interpreta os dados recebidos e exibe a página para o usuário.
